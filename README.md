Лабораторна робота №2: Семантична структура та інструменти перевірки валідності HTML-документу
Проєкт: Вебплатформа психологічної студії «USVIDOM» (м. Буча)
 Тема та мета роботи
Тема роботи: Побудова коректної семантичної структури вебсторінки відповідно до стандарту HTML5 та перевірка коду за допомогою валідатора W3C.
Мета роботи: Сформувати практичні навички створення доступної та логічно структурованої розмітки вебдокумента без використання CSS-стилів; опанувати використання семантичних тегів, адаптивних зображень, машиночитаних даних і форми фільтрації.
